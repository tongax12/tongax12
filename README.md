## 🚀 Proyectos destacados

### 💳 NomaPay — Billetera digital multimoneda
Proyecto final grupal donde estuve a cargo del **backend**: autenticación (JWT con rotación, login con Google OAuth, recuperación de contraseña), modelo de datos para wallets y transacciones, operaciones financieras (exchange, transferencias) con control de concurrencia mediante locks de base de datos, integración con APIs externas de tipo de cambio con caché y fallback, envío de emails transaccionales vía AWS SES y un asistente conversacional con la API de Gemini.
**Stack:** Node.js · TypeScript · Express · PostgreSQL (Sequelize) · Swagger · AWS SES

### 📝 MiniBlog API
API REST para gestión de autores y posts, con diseño de base de datos relacional, documentación interactiva con Swagger/OpenAPI y testing de integración y unitario.
**Stack:** Node.js · Express · PostgreSQL · Swagger · Vitest/Supertest · Railway

### 🤖 GitHub MCP Server
Servidor MCP (Model Context Protocol) que permite ejecutar operaciones de GitHub —crear repos, issues y commits— desde hosts compatibles mediante lenguaje natural. Incluye validación de inputs con Zod, manejo de errores con reintentos automáticos (backoff exponencial) y una suite de tests con mocks sobre el wiring cliente-servidor MCP.
**Stack:** Node.js · TypeScript · MCP · Octokit · Zod · Vitest
